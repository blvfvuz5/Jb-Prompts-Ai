## About

This repository contains German prompts intended for roleplay experiments, testing, and creative exploration with language models such as Gemini and DeepSeek. The prompts are provided for research and educational purposes.

Please use them responsibly.

## Usage

Using the GitHub website:
1. Open the repository.
2. Browse the files and open a prompt file.
3. Copy the prompt you want to test and paste it into the model or tool you are using.

Using the GitHub app (desktop or mobile):
1. Open the repository in the app.
2. Navigate to the prompt file you want to use.
3. Copy the content and use it with your model.
